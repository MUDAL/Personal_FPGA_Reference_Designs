## Running the simulation  

Run the following commands in Windows PowerShell:  
 
1. To simulate the **flatten** module: `cmd.exe /c 'run_flatten_tb.bat'`   
2. To simulate the **matrix_traverse** module: `cmd.exe /c 'run_matrix_traverse_tb.bat'`   
3. To simulate the **memory_controller** module: `cmd.exe /c 'run_memory_controller_tb.bat'`  
4. To simulate the **top-level design**: `cmd.exe /c 'run_task2_tb.bat'`
